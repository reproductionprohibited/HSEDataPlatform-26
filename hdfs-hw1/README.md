# Развёртывание HDFS-кластера

## Описание

В рамках домашнего задания разворачивается распределённый HDFS-кластер на базе Apache Hadoop 3.5.0.

Состав кластера:
- 1 NameNode;
- 1 Secondary NameNode;
- 3 DataNode.

Развёртывание и проверка работоспособности выполняются с помощью Bash-скриптов.

## Инфраструктура

| Сервер | IP-адрес | Назначение |
|---|---|---|
| team-15-en | 10.15.0.10 | Edge, DataNode, Secondary NameNode |
| team-15-nn | 10.15.0.11 | NameNode |
| team-15-00 | 10.15.0.12 | DataNode |
| team-15-01 | 10.15.0.13 | DataNode |

Размещение третьего DataNode и Secondary NameNode на edge-сервере предварительное и требует подтверждения.

## Требования

- Ubuntu Linux;
- Java 17;
- Apache Hadoop 3.5.0;
- SSH-доступ между серверами;
- пользователь `hadoop` для запуска сервисов.

Hadoop установлен в `/opt/hadoop`.

## Развёртывание

Управление кластером осуществляется с edge-сервера.

После объединения скриптов команды запуск и остановка кластера предполагаются следующими:

```bash
./scripts/deploy.sh
./scripts/stop.sh
```

Порядок первоначальной настройки и запуска будет дополнен после интеграции частей команды.

## Проверка состояния кластера

```bash
./scripts/check.sh
```

Скрипт проверяет:
- доступность NameNode;
- наличие процесса Secondary NameNode;
- наличие ровно трёх работающих DataNode;
- отсутствие неработающих DataNode.

Время ожидания готовности — 120 секунд.

Пример успешного вывода:

```text
Checking HDFS...

NameNode: available
Secondary NameNode: available
DataNodes: 3/3
Dead DataNodes: 0

Cluster healthy
```

При неуспешной проверке скрипт завершается с кодом `1`.

## Проверка записи и чтения

```bash
./scripts/smoke-test.sh
```

Скрипт создаёт тестовый файл, загружает его в HDFS, скачивает обратно и сравнивает содержимое.

Дополнительно выполняется проверка состояния блоков и наличия трёх реплик с помощью `hdfs fsck`.

После выполнения тестовые данные удаляются.

Ожидаемый вывод:

```text
Testing HDFS...

Write: OK
Read: OK
Health: OK
Replication: 3/3

Smoke test passed
```

## Проверка сохранности данных

Проверяется сохранность файла после остановки и повторного запуска HDFS.

**1. Создать тестовый файл:**

```bash
./scripts/persistence-test.sh prepare
```

**2. Перезапустить кластер:**

Остановить и повторно запустить HDFS с помощью скриптов развёртывания.

**3. Проверить состояние кластера и файл:**

```bash
./scripts/check.sh
./scripts/persistence-test.sh verify
```

Ожидаемый результат:

```text
Persistence test passed
```

**4. Удалить тестовые данные:**

```bash
./scripts/persistence-test.sh cleanup
```

Команды `prepare` и `verify` необходимо выполнять на одном сервере от одного пользователя.

## Веб-интерфейс NameNode

Для просмотра состояния кластера используется веб-интерфейс NameNode.

С локального компьютера можно настроить SSH-туннель через edge-сервер:

```bash
ssh -L 9870:10.15.0.11:9870 team@111.88.130.160
```

После подключения открыть в браузере:

http://localhost:9870

В интерфейсе можно проверить регистрацию трёх DataNode и состояние HDFS.

- результаты `smoke-test.sh`;
- подтверждение трёх реплик файла;
- результаты проверки сохранности данных после перезапуска;
- подтверждение работы checkpoint Secondary NameNode.
